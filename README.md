# Natahan

Security Operations · Detection Engineering · Threat Intelligence

Building open-source security platforms and ML-assisted defense systems.
Based in Addis Ababa, Ethiopia.

## Work

- [BARAQ](https://github.com/natahanjr/BARAQ) — self-hosted SOC platform for Windows endpoints

  **About:** Production-oriented security operations platform. Collects endpoint telemetry, maps alerts to MITRE ATT&CK, and applies hybrid rule + ML detection with investigation workflows, SOAR automation, threat-intelligence integration, and AI-assisted analysis. Fail-closed production config by default.

- [APT-CTI](https://github.com/natahanjr/APT-CTI) — real-time CTI fusion with explainable ML for early APT prediction

  **About:** Thesis research artefact for live threat-intelligence enrichment of network IDS models. Polls public CTI feeds, builds freshness-aware features, fuses them with traffic statistics (CIC-IDS2017 / UNSW-NB15), and adds TreeSHAP reason codes mapped to MITRE ATT&CK for explainable alerting and early APT-oriented detection.

- [Gedr](https://github.com/natahanjr/Gedr) — AI-enhanced multi-language security analyzer (SAST)

  **About:** Static application security testing across Python, Java, C/C++, JavaScript, Go, Rust, and more. Detects vulnerabilities with heuristic and optional external scanners, audits dependencies (pip-audit, npm-audit, composer-audit), explains findings with AI security reasoning, and generates PDF assessment reports. Runs on modest hardware without a dedicated GPU.

## Focus

Detection engineering, threat intelligence pipelines, explainable machine learning, security automation.
